# Seguimiento

La web guarda aquí un archivo por día (`AAAA-MM-DD.json`) con las monedas que encontró el
escáner ese día y su precio en ese momento, cuando está conectada con GitHub (apartado
**Seguimiento → Guardar también en GitHub**). El workflow `Web` los une en `seguimiento.json`
al publicar la página. Para borrar un día, usa el botón **Borrar** de la web o elimina su archivo.

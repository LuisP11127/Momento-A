Guardar el seguimiento en GitHub

  1. Abre crear una clave (fine-grained token) en GitHub.
  2. Ponle un nombre (por ejemplo, Momento-A). En Repository access elige Only select repositories y tu repositorio.
  3. En Permissions → Repository permissions → Contents elige Read and write.
  4. Pulsa Generate token, copia la clave y pégala aquí.

La clave se guarda solo en este navegador y solo se envía a GitHub. Cada día de seguimiento queda como un archivo en docs/seguimiento/ del repositorio.
